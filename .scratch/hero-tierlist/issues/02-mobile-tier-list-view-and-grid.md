### Core Requirements

1. **Frontend Project Setup**:
   - Initialize Vite + React (TypeScript) + Tailwind CSS in the repository code structure.
   - Configure Tailwind with Dark Cyber palette tokens:
     - Ground: `#0b0f19`
     - Card / Surface: `#131b2e`
     - Borders: `#1e293b`
     - Tier Neon Accents: S+ (`#ff0055`), S (`#f59e0b`), A (`#8b5cf6`), B (`#06b6d4`), C (`#64748b`), D (`#475569`).

2. **Draft-Speed Header**:
   - Concise title (e.g., "MLBB Tier List" / "Meta Radar").
   - Explicit UTC data freshness badge: "Data updated: YYYY-MM-DD HH:mm UTC" dynamically read from dataset `updatedAt`.
   - Patch version tag (e.g., "Patch 2.1.88").

3. **Dense 4-Column Hero Tile Grid**:
   - Mobile-first 4-column layout (`grid-cols-4 gap-1.5` for $\le 480\text{px}$) expanding gracefully on larger screens (`sm:grid-cols-6`, `md:grid-cols-8`).
   - Organized into distinct tier band sections: **S+**, **S**, **A**, **B**, **C**, **D**.
   - Distinct tier section headers with neon badge indicators and clear typography for quick scanning.

4. **Hero Avatar Tile Component**:
   - Hero portrait image loaded from Moonton CDN URL.
   - Progressive loading with local CSS/SVG placeholder on image error or slow network to eliminate layout shifts.
   - Hero name label (sub-11px bold, truncated with ellipsis if exceeding container).
   - Win Rate percentage badge rendered directly on the tile (e.g., `57.9%`).
   - Touch target meeting $\ge 44 \times 44\text{px}$ accessibility standards.

5. **Static Data Ingestion**:
   - App loads the primary normalized dataset (`public/data/tierlist-mythic-1d.json`) generated by Ticket 01.
